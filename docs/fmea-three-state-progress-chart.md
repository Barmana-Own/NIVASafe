# FMEA corrective progress chart

The former ring used only the completion percentage and a neutral remainder. The report now renders separate completed (green), in-progress (orange), and remaining (grey) SVG segments using the existing row-workflow counts and their shared total. The initial center still shows completion percentage. Hover/focus/touch selection of a segment or its legend entry shows that state's percentage and count. Zero-count states remain visible in the legend but produce no artificial ring segments; an empty inventory displays a neutral track.

The component reuses the risk-distribution layout, SVG geometry, segment emphasis/fading, focus, legend hover and percentage animation styles. Status labels are pill-shaped and each legend entry includes its number and percentage. Keyboard activation supports Enter/Space and Escape clears selection.
