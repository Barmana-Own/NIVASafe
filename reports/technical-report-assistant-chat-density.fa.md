## پیاده‌سازی محدود

در نسخهٔ تثبیت‌شدهٔ 527 فایلی، فقط frontend/src/features/assistant/AssistantPage.tsx، آزمون اندازه‌گیری همان بخش و CSS افزوده‌شده در frontend/src/styles.css تغییر کرده‌اند. عنصر، متن، کنترل، قرارداد API یا فایل بک‌اندی تغییر نکرده است. مخفی‌سازی لوگو به identity-icon در assistant-header محدود است. قانون حباب فقط message.user را هدف می‌گیرد و استایل پاسخ دستیار محفوظ است. حداقل عرض ثابت پیام حذف شده، فاصلهٔ داخلی به ۸ در ۱۰ پیکسل و متن کاربر به ۱۴ پیکسل رسیده و فاصلهٔ عنوان و زمان بدون حذف متن کمتر شده است.

کادر پیام با ref محدود و محاسبهٔ ارتفاع خط، padding، حاشیه و box-sizing اندازه‌گیری می‌شود. رویدادهای بومی input، change و reset، تغییر عرض با ResizeObserver و آماده‌شدن فونت، اندازه‌گیری محدود با فریم مرورگر را فعال می‌کنند. بازگردانی بی‌صدای پیش‌نویس غیرهم‌زمان فقط از طریق accessor موجود value همین textarea مشاهده می‌شود؛ getter و setter اصلی React یا مرورگر فراخوانی و هنگام پاک‌سازی بازگردانده می‌شوند. prototype یا شنوندهٔ عمومی تغییری نکرده و اندازه‌گیری، مقدار متن را بازنویسی نمی‌کند. فریم‌ها و شنونده‌ها و observer پاک‌سازی می‌شوند و عنصر جداشده نادیده گرفته می‌شود. Enter دسکتاپ، Shift+Enter، Enter موبایل، IME، سقف ۳۲ هزار نویسه، محافظ ارسال تکراری، کلیدهای پیش‌نویس، ارسال مجدد و رفتار گفتگو حفظ شده‌اند.
