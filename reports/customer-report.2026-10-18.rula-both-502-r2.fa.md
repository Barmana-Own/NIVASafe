## جمع‌بندی

در یک اجرای قبلی، درحالی‌که درگاه هوش مصنوعی پاسخ HTTP 200 داده بود، پاسخ حالت «هر دو سمت» با قرارداد مورد انتظار برنامه تطبیق نکرد و API پاسخ 502 داد. اجرای جداگانه دیگری موفق شد؛ بنابراین خطا متناوب است. قرارداد خروجی در پیام مدل روشن‌تر شد و ثبت دلیل خطای اعتبارسنجی به‌صورت امن اضافه شد، اما چون محیط staging فعلی و دسترسی مجاز به پیکربندی محافظت‌شده در دسترس نبود، این تغییرات هنوز با درگاه واقعی در اجرای جدید تأیید نشده‌اند.

## کار انجام‌شده و شواهد

1. پیام تحلیل RULA برای پاسخ BOTH دقیق‌تر شد تا هر دو نتیجه فقط زیر `sides.LEFT` و `sides.RIGHT` بازگردند و هفت بخش بدن برای هر سمت الزامی بماند.
2. خطاهای قالب‌بندی پاسخ یک کد تشخیصی مجاز و بدون متن پاسخ خصوصی ثبت می‌کنند؛ کنترل‌های رضایت، نقش، فایل و tenant تغییر نکردند.
3. ساخت backend کاندید و ۴۱۴ تست backend، ۲۹ تست متمرکز frontend، typecheck، build، بررسی قرارداد API و ۲۹ بررسی release موفق شدند. جزئیات در [گزارش فنی](technical-report.2026-10-18.rula-both-502-r2.fa.md) و [خلاصه شواهد](evidence/rula-both-502-2026-10-18/evidence-summary.json) آمده است.

## موارد تأییدنشده و اثر آن‌ها

- اجرای کاندید جدید با ArvanCloud، سه درخواست تکراری BOTH، رابط مرورگر و ذخیره‌سازی مجدد اجرا نشد؛ خطای intermittent 502 هنوز رفع‌شده محسوب نمی‌شود.
- یک BOTH ناموفق و یک BOTH موفق در کاندید قبلی ثبت شده‌اند. در اجرای ناموفق دو درخواست بالادستی HTTP 200 بوده‌اند، ولی جزئیات شکل پاسخ حفظ نشده است؛ کمبود دسترسی vision اثبات نشده است.
- کاندید جدید منتشر نشده و مجوزهای پردازش تصویر در محیط live تغییر نکرده‌اند. سرور API محلی فقط پاسخ سلامت HTTP 200 با نسخه `0.1.0` می‌دهد؛ هویت فایل اجرایی آن برای حساب فعلی قابل خواندن نبود.
- تأیید مرورگر و Safari/WebKit انجام نشد. صفحه باز مرورگر به مسیر قدیمی staging اشاره می‌کند و Playwright نصب نیست.

## اقدام لازم برای ادامه

مسئول مجاز Windows باید runbook موجود در `reports/evidence/rula-both-502-2026-10-18/ADMIN-RUNBOOK.md` را با همان هویت staging که از قبل به تنظیمات محافظت‌شده دسترسی دارد اجرا کند. تا دریافت شواهد اجرای جدید، انتشار backend انجام نمی‌شود. هیچ فایل live، سرویس، پایگاه داده یا بارگذاری تولیدی در این مرحله تغییر نکرده است.
