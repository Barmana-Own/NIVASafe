## محدوده، مبنا و بازیابی

فرانت‌اند React/Vite، API مبتنی بر Fastify، ذخیره‌سازی Prisma/MySQL، کنترل‌های رضایت موجود و فرایند ارزیابی قابل ویرایش، مبنای حفظ‌شده پروژه هستند. عیب، مختصات تولیدشده مفاصل RULA است که به‌طور قابل اتکا بر آناتومی قابل مشاهده منطبق نمی‌شود. اصلاح، آشکارساز محلی جداگانه‌ای برای مختصات مفاصل اضافه می‌کند؛ ارائه‌دهنده مولد موجود همچنان پیشنهادهای قابل ویرایش پوسچر و اطلاعات کلی زاویه دید را تولید می‌کند.

نسخه پشتیبان محلی تأییدشده: `backups/NIVASafe-before-landmark-fix-20261022-aee9d06.zip` با SHA-256 برابر `b1581bf6a5b8fa5ab37e196ad18afc7bde4361688035738026c869b6e2ca4a00` و اندازه ۱۶٬۰۸۴٬۹۵۵ بایت. مدرک پشتیبان، ۹۵۷ فایل و کنترل CRC آرشیو را ثبت کرده است. این مدرک، ارسال موفق به GitHub را اثبات نمی‌کند. نسخه عملیاتی immutable قبلی و پشتیبان عملیاتی خصوصی آن، مبنای بازیابی باقی می‌مانند.

FMEA، چیدمان محصول و مسیرهای نامرتبط خارج از محدوده اصلاح هستند. worker محلی جدید به migration یا تغییر schema دیتابیس نیاز ندارد.

## بررسی امنیت و حریم خصوصی

احراز هویت، سازمان و مجوز ارزیابی پیش از پردازش بارگذاری بررسی می‌شوند. پیش از استنتاج CPU، هویت، سازمان/نقش/اشتراک، دسترسی AI، رضایت جاری حساب و مجوز صاحب تصویر دوباره کنترل می‌شوند. رزرو سهمیه توکن خارجی و ثبت اجباری مجوز ارسال حفظ شده‌اند؛ مجوز پس از ثبت غیرهم‌زمان audit و پیش از ارسال نیز دوباره بررسی می‌شود.

تنها مسیرهای مطلق محلی فایل اجرایی، worker و مدل که اپراتور تنظیم کرده پذیرفته می‌شوند. shell، مسیر انتخاب‌شده در درخواست یا ارث‌بری اسرار برنامه به فرایند فرزند وجود ندارد. Python با `-I` اجرا و تصویر از stdin ارسال می‌شود. محدودیت‌ها شامل ورودی تصویر ۱۰ MiB، ۲۴ میلیون پیکسل، stdout برابر ۶۴ KiB، زمان ۲۰ ثانیه و یک استنتاج فعال در هر فرایند API است. پس از شکست، ظرفیت تا خروج قطعی worker آزاد نمی‌شود؛ جزئیات تشخیصی به کاربر بازگردانده نمی‌شوند.

هش مدل `5134a3aad27a58b93da0088d431f366da362b44e3ccfbe3462b3827a839011b1` در Node و Python بررسی می‌شود. worker به MediaPipe 0.10.32 روی Python اختصاصی 3.12 AMD64 وابسته است. بررسی مستقل، غیرفعال بودن ارث‌بری دسترسی پوشه‌های مدل و اجرا با دسترسی فقط SYSTEM/Administrators و قانون فعال Block خروجی برای تمام پروفایل‌ها، دقیقاً روی `python.exe` اختصاصی و هر آدرس مقصد را تأیید کرد. آزمون واقعی TCP عامل اصلی با خطای مجوز Windows شماره 10013 متوقف شد. سیاست سراسری فایروال تغییر نکرد.

استنتاج محلی مفاصل، سرویس خارجی جدیدی برای تصویر اضافه نمی‌کند. انتقال موجود تصویر به ArvanCloud همچنان تحت کنترل رضایت است. تضمین نگهداری، حذف، استفاده آموزشی و محل پردازش خارجی تأیید نشده و این اصلاح ادعای تأیید آنها را ندارد. در مرز جدید بررسی‌شده مستقل، عیب امنیتی نیازمند اصلاح شناسایی نشد. انتشار نهایی باید این کنترل‌ها را حفظ کند.
