# کارت‌های لاگ فعالیت — گزارش مشتری

| NIVASafe | مشتری | فارسی | 2026-10-23 | 1405-08-01 | release-activity-log-cards-20261023-01 |

فعالیت‌های ثبت‌شده در لاگ فعالیت به چهار کارت در هر ردیف دسکتاپ تبدیل شدند و در عرض کمتر سه، دو یا یک ستون نمایش داده می‌شوند. هر شش فیلد اصلی، مقادیر کامل و دکمهٔ جزئیات حفظ شده‌اند. جست‌وجو، فیلتر رویداد و موجودیت، بازنشانی، تلاش دوباره و باز و بسته‌شدن جزئیات رفتار قبلی را دارند. بخش یا کنترل نامرتبطی تغییر نکرده است.

## کیفیت و انتشار

| بررسی | نتیجه |
|---|---|
| کامپایل دامنهٔ مشترک | PASS |
| بررسی نوع، lint، کامپایل و ساخت فرانت | PASS |
| آزمون مرورگر روی کد واقعی با دادهٔ مصنوعی | PASS — 17 |
| آزمون مرورگر روی فایل‌های منتشرشده | PASS — 3 |
| بازبینی امنیت و حفظ محدودهٔ تغییر | PASS |
| تطبیق فایل عمومی و حفظ هویت API | PASS |
| آزمون واحد، بک‌اند و ممیزی وابستگی | NOT_RUN — فقط CSS؛ منطق و وابستگی تغییری نکردند |
| تغییر فعالیت یا حساب واقعی | NOT_RUN — فقط پاسخ‌های مصنوعی API |

روی سرور سامانه منتشر شد. برای این اصلاح محدود، مانع خارجی یا اقدام الزامی دیگری از مشتری باقی نمانده است.
