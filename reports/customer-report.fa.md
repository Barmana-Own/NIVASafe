## خلاصه

آستانه تشخیص اختلاف تصویری از ۸٪ به ۲٪ کاهش یافت و ورودی‌های آزمون مرورگر پایدارتر شدند. مجموعه تصویری در دو اجرای کامل پیاپی موفق بود و یک تغییر چیدمان عمدی و قابل‌توجه نیز توسط آزمون رد شد. رفتار، ظاهر production و API سامانه برای این مرحله تغییر نکرده‌اند.

## تغییرات قابل مشاهده در کیفیت تحویل

- پوشش تصویری موجود حفظ شد و ۱۶ تصویر مبنا برای صفحه‌های فهرست و فرم FMEA/RULA، دانش، اعلان‌ها، اعضا و پروفایل اضافه شد.
- صفحه‌های مهم در عرض‌های موبایل، تبلت و دسکتاپ آزمایش شدند؛ فارسی/RTL، انگلیسی/LTR و پوسته‌های انتخاب‌شده نیز پوشش دارند.
- آزمون‌ها دیگر برای دریافت فونت Vazirmatn به دسترس‌پذیری لحظه‌ای CDN بیرونی وابسته نیستند؛ فایل‌های فونت فقط در محیط آزمون استفاده می‌شوند.

## کیفیت و اعتبارسنجی

- آزمون تصویری: ۵۲ از ۵۲ در دو اجرای کامل متوالی.
- آزمون‌های تعاملی مرورگر: ۹۰ از ۹۰.
- آزمون‌های overflow: ۱۰۸ از ۱۰۸.
- آزمون‌های Vitest: ۱۲۴ از ۱۲۴؛ lint، typecheck و build نیز موفق شدند.
- آزمون منفی کنترل‌شده: جابه‌جایی ۱۴۰ پیکسلی گزارش RULA به اختلاف ۳٪ انجامید و با آستانه ۲٪ شکست خورد؛ پس از حذف تغییر موقت، baseline اصلی پاس شد.

## محدودیت‌ها و وضعیت انتشار

اجرای واقعی GitHub Actions مشاهده نشده و هیچ انتشار یا استقرار انجام نشده است. محیط محلی از pnpm 11.19.0 استفاده کرد، در حالی که پیکربندی مخزن/CI نسخه 10.13.1 را تعیین می‌کند؛ بررسی اجرای Corepack با آن نسخه به علت محدودیت دسترسی به cache سیستم انجام نشد. build موفق بود اما هشدار اندازه chunk جاوااسکریپت بزرگ‌تر از ۵۰۰ کیلوبایت را گزارش کرد.

## جمع‌بندی

مرحله سخت‌گیری و پایدارسازی آزمون تصویری در محیط محلی تکمیل شد. پیش از اتکا به نتیجه CI، اجرای workflow روی GitHub و با نسخه pnpm تعیین‌شده باید مشاهده شود.

## به‌روزرسانی تحویل — ۱۰ مهر ۱۴۰۵

در ادامه، آماده‌سازی صفحه‌ها برای آزمون مرورگر بر اساس محتوای واقعی، پایان بارگذاری، فونت‌ها، تصاویر و تثبیت چیدمان انجام شد. همچنین آزمون‌های اشتراک آزمایشی اکنون زمان ساخت و بررسی انقضا را از یک لحظهٔ کنترل‌شده می‌گیرند؛ مدت آزمایشی ۱۴روزه و قواعد دسترسی تغییر نکرده‌اند.

اعتبارسنجی تکمیلی شامل ۹۶ آزمون تعاملی مرورگر، ۱۰۸ آزمون overflow، دو اجرای پیاپی مجموعهٔ تصویری با نتیجهٔ ۵۲ از ۵۲، ۱۲ آزمون مرزی اشتراک، ۱۵۲ آزمون backend در اجرای تک‌worker و ۱۲ آزمون دامنه بود. lint، typecheck و build مربوط به backend نیز موفق شدند. یک اجرای موازی کامل backend یک timeout گذرا در آزمون provider هوش مصنوعی داشت؛ همان آزمون به‌تنهایی و کل مجموعه با یک worker موفق شدند.

هیچ baseline تصویری در این مرحله به‌روزرسانی نشد. تغییر اشتراک فقط seam داخلی ساعت و آزمون‌ها را در بر می‌گیرد؛ API، پایگاه داده و رفتار کاربر تغییر نکرده‌اند. اجرای CI راه‌دور و انتشار همچنان انجام نشده است.

## به‌روزرسانی دروازهٔ نهایی کیفیت — ۱۰ مهر ۱۴۰۵

بررسی‌های محلی کیفیت انتشار موفق شدند: ۹۹ آزمون تعاملی/دسترسی مرورگر، ۱۰۸ آزمون overflow، ۵۲ مقایسهٔ تصویری سخت‌گیرانه، ۲۹۵ تست واحد/دامنه/بک‌اند در workspace، به‌علاوهٔ lint، typecheck، build، بررسی قرارداد API و verifier انتشار. آزمون‌های مرورگری محلی برای پیش‌نمایش PDF و ویدئو، focus صفحه‌کلید در modal، قفل اسکرول پس‌زمینه و بازگشت focus نیز اضافه و اجرا شدند.

در این دروازه رفتار production و baseline تصویری تغییر نکرد. workflow گیت‌هاب برای pull request و push تنظیم شده است، اما نتیجهٔ اجرای remote CI مشاهده نشد. هیچ استقرار یا درخواست production انجام نشد. build همچنان هشدار غیرمسدودکنندهٔ اندازهٔ بالای فایل JavaScript را نشان می‌دهد.

در نخستین اجرای مجموعهٔ مرورگری، آزمون گزارش RULA در عرض بزرگ timeout شد؛ اجرای همان آزمون و اجرای کامل بعدی موفق بودند و timeout دوباره رخ نداد. این مورد برای پایش در CI ثبت شده است و نیازی به تغییر رفتار برنامه یا baseline تصویری نداشت.
