## علت‌ها و اصلاحات

مجوز پلتفرم در سرور خالی بود؛ رضایت صحیح حساب جای آن را نمی‌گیرد. این پیش‌نیاز واقعی باز مانده است. در نسخهٔ فعال، تحلیل به مرحلهٔ دوم و تکمیل فعالیت وابسته بود و سرور نیز تأیید منسوخ هر تصویر را علاوه بر رضایت حساب می‌خواست. شروع خودکار از بارگذاری، ادامه در مرحلهٔ دوم و پذیرش اطلاعات تکمیلی خالی اصلاح شد. تایپ شرح فعالیت، درخواست تصویری جاری را لغو و دوباره صف نمی‌کند. ذخیرهٔ نتیجهٔ اولیه و اتصال عکس به ارزیابی در جریان اکنون مجاز است؛ تأیید نهایی همچنان بازبینی تمام سمت‌ها و تصاویر را الزام می‌کند. Git اصلی پیش‌تر قرارداد جدید رضایت حساب و درخواست تصویری مستقل از متن را داشت؛ اصلاحات آن بدون بازگرداندن کنترل‌های قدیمی اعمال شد.

چهار فراخوانی موفق و واقعی GPT-5-Mini در سقف مشترک شش تلاش انجام شد. فراخوانی نخست RIGHT خطای اتصال پیش‌نویس را آشکار کرد؛ سپس RIGHT/LEFT/BOTH بررسی شد. ادامهٔ آزمون، پاسخ تأییدشدهٔ RIGHT را دوباره استفاده کرد تا هزینهٔ تکراری ایجاد نشود. عکس واقعی کارکنان یا گزارش خصوصی FMEA ارسال نشد. R8 آزمایشی، مدل جایگزین و تأیید ساختگی فعال نشد؛ مدل ارزیابی GPT-5-Mini و مدل چت DeepSeek-V4-Flash باقی ماند.

## شکست‌ها و رفع آنها

تست‌های جدید ابتدا رد رضایت منسوخ تصویر، نیاز نادرست به متن فعالیت، نبود شروع خودکار و الزام نادرست بازبینی برای پیش‌نویس را بازتولید کردند؛ پس از اصلاح عبور کردند. خطاهای خودِ آزمون شامل مسیر ویندوزی --import، انتظار 403 به‌جای پاسخ مجاز 401 برای مرز سازمان، و مقایسهٔ بیت‌به‌بیت اعشار JSON پایگاه داده بود. خطاها ثبت و اصلاح شدند؛ تلرانس 1e-9 تنها در مقایسهٔ تست استفاده شد و آستانهٔ هندسهٔ محصول تغییر نکرد. در checkout تمیز Git ابتدا خروجی shared/domain ساخته نشده بود؛ با ساخت وابستگی، خطاهای جمع‌آوری رفع شدند. انتظار متنی وابستگی effect با رفتار جدید هماهنگ شد و تست رفتاری حفظ شد. دو پیش‌بررسی انتشار پیش از تغییر سرویس متوقف شدند؛ ACL اختصاصی SYSTEM/Administrators پیش از نوشتن محیط بازگشت اعمال و با icacls تأیید شد.

## انتشار، امنیت و حفظ پروژه

سه ماژول کامپایل‌شدهٔ سرور و زمان‌بندی RULA از مبنای نسخهٔ فعال منتشر شدند. CSS فعال، فایل‌های قبلی، صفحات، نقش‌ها، سهمیه‌ها، مدل‌ها و schema حفظ شدند. شاخهٔ Git کنترل‌های جدیدتر FMEA و تست‌های آن را نگه می‌دارد؛ تغییرات نامرتبط و ثبت‌نشدهٔ پوشهٔ اصلی منتشر نشدند. این انتشار به معنی استقرار تمام فایل‌های Git نیست.

سلامت عمومی، چهار مسیر HTML و 18 فایل JavaScript تأیید شدند؛ مسیرهای محافظت‌شده برای ناشناس 401 باقی ماندند. فایل .env دست‌نخورده است. قابلیت فنی RULA_IMAGE_VISION_SUPPORTED_PROVIDER با آزمون واقعی ثبت شد؛ مجوز حریم خصوصی خالی باقی است. فهرست مجاز سازمانی اضافه نشد. بازگشت: بازیابی config و index از C:/ProgramData/NIVASafe/backups/release-rula-root-repair-20261021-01 و راه‌اندازی entry قبلی و بررسی سلامت/نسخه. فایل‌های قدیمی موجودند و migration لازم نیست. cold start بسته و تمرین بازگشت index موفق بود؛ بازگشت واقعی دوبارهٔ سرویس NOT_RUN است.

بررسی امنیتِ محدودهٔ تغییر PASS است: رضایت معتبر سروری، ثبت رویداد پیش از ارسال، کنترل نقش و سازمان، اعتبارسنجی و سقف تصویر، سهمیه، دسترسی خصوصی و جلوگیری از تأیید نهایی نتیجهٔ بازبینی‌نشده. خروجی Staging به hash تصویر مصنوعی، مقصد و مدل مشخص و سقف پایدار شش تلاش محدود شد. حساب‌های آزمایشی غیرفعال و نشست‌ها لغو شدند. wrapper آزمون در تولید نصب نشد. وابستگی تازه‌ای اضافه نشد؛ audit جامع تازهٔ وابستگی‌ها NOT_RUN است.
