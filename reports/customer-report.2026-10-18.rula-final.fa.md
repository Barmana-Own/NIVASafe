## خلاصه

کاندید نهایی در محیط آزمایشی ایزوله build شد و آزمون‌های خودکار آن موفق بودند. تلاش احراز‌شده تصویر در فرایند staging انجام شد که پیش از build نهایی تغییر تشخیصی شروع شده بود؛ بنابراین تطابق runtime با آخرین build تأیید نشد. درخواست تصویر از ArvanCloud پاسخ HTTP 401 گرفت؛ نتیجه RULA ایجاد یا ذخیره نشد و انتشار زنده انجام نگرفت.

## کارهای تأییدشده

1. درخواست تصویری واقعی از مسیر احراز هویت‌شده برنامه تا gateway ارسال شد؛ تصویر فقط synthetic بود.
2. درخواست پیشنهاد متنی از همان محیط با HTTP 200 پاسخ گرفت.
3. اصلاح قالب درخواست GPT-5-Mini، حذف reasoning_effort برای تصویر و محدودیت timeout در کاندید حفظ شد.
4. آزمون backend با ۴۱۱ تست، frontend با ۳۳۹ تست، build و بررسی قرارداد API موفق شدند.
5. پایگاه staging از دیتابیس زنده جدا بود؛ رکورد ارزیابی RULA پس از خطای ارائه‌دهنده ذخیره نشد.

## موارد باقی‌مانده

- ArvanCloud باید دسترسی multimodal/vision مدل GPT-5-Mini را برای اعتبارنامه staging تأیید یا فعال کند.
- پس از آن باید آزمون RIGHT، LEFT و BOTH، بازبینی انسانی، ذخیره، ورود مجدد، بارگذاری مجدد و گزارش برای همین کاندید تکرار شود.
- انتشار زنده انجام نشده است. هویت دقیق باینری backend فعال و تنظیمات محافظت‌شده قابل تأیید نبود.
- خطاهای تاریخی migration دست‌نخورده‌اند؛ migration زنده اجرا نشد.
