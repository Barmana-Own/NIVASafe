# تایپوگرافی سفید صفحهٔ ورود — گزارش فنی

| Project | Language | Gregorian | Jalali | Release |
|---|---|---|---|---|

تایپوگرافی سفید اصلیِ فارسی و انگلیسی برای پوستهٔ تیره در هدر دسکتاپ و بخش اصلی موبایل منتشر شد. کنترل‌های موجودِ پوسته و زبان بلافاصله فایل اصلیِ مناسب را انتخاب می‌کنند. پوستهٔ روشن همان تایپوگرافی آبی قبلی را حفظ کرده است. لوگوهای نمادین، رفتار ورود، تمام صفحه‌های نامرتبط و API تغییر نکرده‌اند.

| بررسی | وضعیت |
|---|---|
| آزمون فرانت | PASS — 533/533 |
| نوع، lint پیکربندی‌شده، کامپایل و ساخت تولید | PASS |
| پذیرش مرورگر / نسخهٔ منتشرشده | PASS — 24 / 3 |
| بایت PNGهای اصلی، رنگ طبیعی و شفافیت | PASS |
| امنیت محدود، اثبات حفظ منبع و اجرای سرور | PASS |

آزمون واحد بک‌اند و دامنه و بررسی آسیب‌پذیری وابستگی‌ها: NOT_RUN؛ منبع و وابستگی‌های آن‌ها تغییر نکرده‌اند. ارسال اعتبارنامهٔ واقعی و بررسی سرویس زندهٔ اینماد: NOT_RUN؛ پذیرش ناشناس مرورگر از fixtureهای فونت و نشان استفاده می‌کند.

تنها منبع تصویر دو تایپوگرافیِ موجود به context فعلیِ ظاهر متصل شد. یک CSS محدود در انتهای استایل‌ها فیلتر سفیدکنندهٔ قبلی را خنثی می‌کند. محدودیت‌های اندازه و نسبت طبیعی حفظ شده‌اند. دو PNG جدید با فایل‌های ZIP ارسالی بایت‌به‌بایت یکسان‌اند؛ هر ۲۱ لینک استایل قبلی به همان ترتیب باقی مانده و یک استایل محدود اضافه شده است. 925 فایل عمومی قبلی به‌جز index و 368 فایل خصوصی بک‌اند، محیط، پراکسی و PID سرویس API برابر 10380 حفظ شده‌اند. راه‌اندازی مجدد، مهاجرت داده یا تغییر وابستگی انجام نشده است. بازگشت با بازیابی اتمی C:/NIVASafe/.local/login-white-typography-20261023-01/index.before.html انجام می‌شود.

اجرای نخست آزمون، ۵۳۲ مورد از ۵۳۳ مورد را گذراند؛ یک آزمون موجود مقدار inline و صرفاً آبیِ srcSet قبلی را الزام می‌کرد. آن بررسی با منبع وابسته به پوسته جایگزین شد و اکنون وجود هر دو مسیر فارسی و انگلیسیِ سفید و آبی را نیز الزام می‌کند. هیچ آزمونی حذف نشد و تغییرات نامرتبط قبلیِ فایل آزمون در ریشه حفظ شدند. شکست اولیه بایگانی شده و اجرای نهاییِ کامل ۵۳۳ مورد از ۵۳۳ مورد را گذرانده است. در بررسی بعدی روی دامنهٔ عمومی، ابزار آزمون پوستهٔ فعال را دوباره درخواست می‌کرد، درحالی‌که منوی موجود فقط پوستهٔ دیگر را نشان می‌دهد. آزمون اکنون به پوستهٔ دیگر و سپس به پوستهٔ اولیه جابه‌جا می‌شود. نتیجهٔ ۲ از ۳ و تأیید انتشار قبلی بایگانی شده‌اند؛ تمام ۲۴ بررسی نسخهٔ کاندید و ۳ بررسی عمومی با همان منبع و ساختِ بدون تغییر دوباره اجرا شدند.

مراحل محدود ۰۱ تا ۰۳ دارایی، طراحی و فرانت؛۰۴ تا ۰۷ حفظ بک‌اند، داده، API و ورود؛۰۸ بازبینی دقیق منبع و مرز فایل‌های ثابت؛۰۹ آزمون و ساخت؛۱۰ بررسی ۲۴ حالت واکنش‌گرا، زبان و پوسته در مقایسه با منبع اصلیِ ثبت‌شده؛۱۱ انتشار فایل‌های ثابت و تعویض اتمی index؛۱۲ بازخوانی مستقل شواهد، سه بررسی مرورگر واقعی روی دامنهٔ عمومی، فایل‌ها، اجرای سرور و مستندات را پوشش می‌دهند. این تأیید فقط برای همین تغییر محدود است و تأیید کل محصول محسوب نمی‌شود.
